✓ No built-in time limit

This version does not use the three-minute Browsercraft trial. Play sessions are not cut off by a timer in this website. The port is still experimental and can crash or fail to load.

Saving your world

The Gaius singleplayer port saves to browser storage. For the most reliable saves, use Play in full tab and return to the same browser/profile; embedded storage can be partitioned or cleared. Worlds for 26.2 and 26.3 are separate.

Compatibility & source

Best on current Chrome or Chromium desktop. First load may take a while. The actual runtime is served by Gaius on GitHub Pages, not by this website. If the embed stays blank, open the game directly.
