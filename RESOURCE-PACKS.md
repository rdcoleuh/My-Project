## 6.65 — Bedrock Samples HUD texture support (October 26, 2026)

When a player imports the Bedrock Samples resource ZIP, MineWorld reads `resource_pack/textures/ui/heart.png`, `heart_half.png`, `heart_background.png`, `hunger_full.png`, `hunger_half.png`, `hunger_background.png`, `hotbar_0.png` through `hotbar_8.png`, and `selected_hotbar_slot.png`. The player's own pixels are used for the ten-heart/ten-hunger display and nine hotbar cells. Empty sprite art is composited beneath full/half sprites; import refresh occurs after texture state commits. Nearest-neighbor scaling, original procedural fallback, touch controls and existing saves remain unchanged. No proprietary bitmaps are committed.

## 6.65 — Bedrock Samples HUD texture support (October 26, 2026)

When the player imports and privately stores the official Bedrock Samples resource ZIP, MineWorld now reads its `resource_pack/textures/ui/heart.png`, `heart_half.png`, `heart_background.png`, `hunger_full.png`, `hunger_half.png`, `hunger_background.png`, `hotbar_0.png` through `hotbar_8.png`, and `selected_hotbar_slot.png`. The actual imported pixels are used for the 10-heart/10-hunger display and each hotbar cell, with the empty sprite underneath partially filled icons. Imported block and item sprites also refresh once the pack is committed, including after restoring the browser's saved pack. Nearest-neighbor scaling and procedural fallbacks remain; no proprietary bitmap is committed to the repository. Java modern HUD sprite names and local folder imports are also supported. A Bedrock archive without these UI assets retains MineWorld's original fallback HUD.
