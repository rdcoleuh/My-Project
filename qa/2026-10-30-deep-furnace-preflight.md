# MineWorld deep-world furnace migration preflight — 2026-10-30

## Reproduction and risk
The experimental legacy-save migration planner converted block edits and player positions but did not inspect `furnaces`. A future migration consuming that preview could silently drop input, fuel, output and cooking progress, or accept duplicate positions that the furnace restorer would collapse.

## Fix
The preview now validates every saved furnace's dimension, absolute legacy Y coordinate, X/Z bounds, unique location, stack keys/quantities and finite burn/progress timers. It returns a detached, frozen `furnaces` array without shifting coordinates or changing the original save. Unknown but syntactically safe inventory keys remain intact.

## Verification
Seven Node regression tests cover inventory preservation, older saves, duplicates, coordinates, malformed stacks, timers and live-height guardrails. A direct in-memory V8 check passed before the commit. GitHub Actions results must be checked separately.

## Limits
This is migration preflight only. The playable Overworld remains Y 0–47 (sea level 14). No full Y -64..319 gameplay, world migration, dedicated before/after browser video, or boss victory is claimed. Browser smoke artifacts, if generated by CI, show general gameplay rather than this preview-only safeguard. Synthetic resource-pack fixtures are not player-owned Minecraft artwork.
