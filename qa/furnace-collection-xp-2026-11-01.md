# Furnace collection experience — 2026-11-01

## Reproduction and fix

Before this increment, collecting smelted output through the three-slot furnace
UI transferred the resulting item but never granted Survival experience. A
player could smelt and collect iron indefinitely without progressing XP.

The UI now awards original MineWorld whole-point experience only after a
successful reconciled output withdrawal. Standard registered smelting products
grant one XP per item; netherite scrap grants two. Unsupported saved/custom
output items, blocked/full-inventory collections, and fuel/input withdrawals
award zero. This is not an exact Minecraft Java/Bedrock fractional XP table.

## Verification plan

- Node regression tests exercise real engine smelting and reconciled output
  withdrawals, including a full inventory, partial collection, and unknown items.
- Desktop and mobile Chrome smoke paths assert the experience HUD increases by
  exactly one for each of two separately collected iron ingots while a synthetic
  player-importable texture pack is enabled.
- Existing save schema, furnace slots, recipes and fuel timing are unchanged.
- The resource-pack fixture is independently generated, not the user's pack.
- No dedicated before/after recording is claimed for this increment; general
  smoke-test recordings are generated by the existing CI workflow if it succeeds.
